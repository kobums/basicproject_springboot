## Project Overview

basicproject_springboot: the Spring Boot starter for gomachine (`buildtool-model`). Hand-written code covers only auth, JWT,
upload and security. All table CRUD (entity / repository / service / controller) is generated Kotlin from `model.json` + the DB schema.

- Spring Boot 4.1.2, Kotlin 2.3.21 (Boot-managed), Java 21 toolchain, Gradle 9.8.2 wrapper, JJWT 0.13, MariaDB (H2 for tests)
- Base package `com.basicproject.api` (`src/main/kotlin/com/basicproject/api`)

## Commands

```bash
./gradlew build      # compile + tests, no DB needed (H2 in MariaDB mode loads db/schema.sql)
./gradlew test
./gradlew bootRun    # loads .env into the environment; needs `docker compose up -d db`
./gradlew gen        # runs `buildtool-model .` (must be on PATH, DB must be up)
docker compose up -d db
```

## Generated vs hand-written code

- Files starting with `// Code generated by gomachine. DO NOT EDIT.` are generated: `entity/`, `repository/`, `service/`,
  `controller/`, `support/DateParams.kt`. Never edit them; change `model.json` / `db/schema.sql` and regenerate.
  They are committed so the project builds out of the box; regenerate after schema changes and commit the result.
- `config/SessionProvider.kt` is created by gomachine only if missing (user-owned). `config/SecuritySessionProvider.kt` implements it
  from the Spring Security principal (`security/AuthPrincipal`).
- Hand-written classes must not reuse generated simple names (`User`, `UserRepository`, `UserService`, `UserController`, `Board*`, ...):
  Spring bean names and JPA entity names would clash. Auth code (`auth/AuthService`) uses the generated `User` entity and `UserRepository`
  (email lookup via `Specification`).

## Auth / security

- Unified JWT shared with basicproject_go / Rust: HS256 only, key = `JWT_SECRET` UTF-8 bytes (>= 32 bytes, startup fails otherwise),
  claims `{sub: "<id>", id, email, level, iat, exp}` in integer seconds, 24h. Parsing: `id` else numeric `sub`, `level` optional.
- `JwtAuthenticationFilter` sets `AuthPrincipal(id, email, level)`; any invalid token = anonymous (never 500).
- `SecurityConfig`: stateless; `/api/auth/login|signup` public, `/api/auth/**` and `/api/upload` authenticated, other `/api/**`
  permitted at the filter level because generated controllers return 401 themselves via `SessionProvider` (generated `POST /api/user` is open, like Go).
- One `PasswordEncoder` (bcrypt) bean is shared by `AuthService` and the generated `UserService`.
- Signup (`POST /api/auth/signup`) sets level 1; generated `POST /api/user` writes level 0 (protected column).
